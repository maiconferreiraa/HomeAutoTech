# Home Automation Technology

Site institucional da Home Automation Technology, empresa de automação residencial em Lagoa Santa/MG.

Site: https://www.homeautotech.com.br/

## Stack

- HTML5 + CSS3 (`style.css`)
- [Bootstrap 5](https://getbootstrap.com/) e [Bootstrap Icons](https://icons.getbootstrap.com/)
- [Swiper](https://swiperjs.com/) para os carrosséis
- Formulário de contato via [formsubmit.co](https://formsubmit.co/)

## Estrutura

```
index.html      Página principal
obrigado.html   Página de confirmação após envio do formulário
style.css       Estilos do site
robots.txt      Diretivas para buscadores
sitemap.xml     Mapa do site para SEO
images/         Imagens e vídeos do site
```

## Deploy

O deploy é feito automaticamente a cada push na branch `main`.
